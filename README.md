# Instituto do Sono Jundiaí — Site Institucional

Site institucional minimalista do Instituto do Sono Jundiaí.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Deploy

Projeto preparado para Vercel.

- Domínio principal: `institutodosonojundiai.com.br`
- Portal de laudos: `https://laudos.institutodosonojundiai.com.br/paciente`
