# OLFATOCARE-SITE V2

Versão 2 do site institucional Olfato Care.

Principais ajustes:
- hero claro com fotografia à direita;
- logo oficial Olfato Care mantido;
- cabeçalho azul mais equilibrado;
- quatro pilares Avaliar, Medir, Tratar e Acompanhar;
- seções mais próximas do mockup aprovado;
- acesso ao SNOT-22 mantido em snot-22.olfatocare.com.br.
